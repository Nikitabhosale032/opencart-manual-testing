# OpenCart Manual Testing

Manual testing of the OpenCart demo store (https://demo.opencart.com).

## What I tested
- Registration (7), Login and Logout (5), Cart (4)
- Checkout, Order History and Returns (11 cases) were Blocked: all products on the demo store were out of stock, so no order could be placed

## Results
- 27 test cases: 16 passed, 0 failed, 11 blocked

## Files
- OpenCart_QA_TestCases.xlsx: requirements, test cases with results, bug report and test summary

## Tools
Excel, Chrome
